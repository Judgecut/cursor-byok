# 界面显示调整计划

记录日期：2026-11-10。状态：已实施并归档（2026-11-11）。

## 1. 概览：调用记录、供应商、模型三个页签

当前概览表格使用“模型 / 供应商”合并列，默认只显示模型，展开模型行后才显示供应商。

- 参考用户提供的 CC Switch 截图，将概览下方统计区分为“调用记录 / 供应商 / 模型”三个页签；供应商和模型分别汇总，不再通过展开模型行查找供应商。本安排替代此前单张供应商与模型组合表的方案。
- 调用记录页签：展示当前时间范围、供应商筛选下的调用列表，复用现有调用表格与详情入口；完整调用详细统计仍保留在独立调用页面。
- 供应商页签：每行一个供应商，汇总该供应商在当前筛选内所有模型的调用、Token、费用、成功率、平均速度和首 Token。
- 模型页签：每行一个模型，汇总所选供应商范围内该模型的指标；选择“全部供应商”时，同一模型跨供应商汇总，避免重复计数。
- 首次进入概览默认打开模型页签，直接展示各模型的总 Token 消耗；切换其他页签后，在当前页面生命周期内保留用户选择。
- 现有供应商端点、定价来源和历史状态等辅助信息按实际归属展示；一个汇总行涉及多种定价来源时不标成单一定价来源。
- 切换页签只改变下方展示维度，保持当前时间范围、供应商筛选和上方统计结果。

目标页面结构（统计卡片在图表上方）：

```text
概览
├── 页面操作区：时间范围 / 供应商筛选（默认全部）/ USD·CNY / Token·费用 / 柱状·曲线 / 刷新
├── 统计卡片：缓存命中率 / 调用 / 平均速度 / 首 Token / Token / 费用
├── 趋势图与活动日历：使用同一供应商筛选
└── 页签区：调用记录 | 供应商 | 模型
    ├── 调用记录：筛选后的调用列表 → 现有单次调用详情
    ├── 供应商：供应商 | 总 Token | 平均速度 | 首 Token | 调用 | 成功率 | 输入 | 缓存读 / 写 | 输出 | 费用 | 单次均值
    └── 模型：模型 | 总 Token（含占比）| 平均速度 | 首 Token | 调用 | 成功率 | 输入 | 缓存读 / 写 | 输出 | 费用 | 单次均值
```

### 1.1 供应商筛选与统计联动

- 概览页面操作区增加独立供应商筛选，支持“全部”、单选和多选；供应商选项包含有历史调用但当前已停用的供应商，并标注历史状态。
- 筛选项表示供应商本身，而非某个供应商下的单一模型；同名供应商以端点等信息区分，不按显示名称合并。
- 当前代码中的 `supplier_key` 实际标识供应商与模型组合；实施时按现有 `source_kind + endpoint_key` 供应商归属归组，选择供应商应覆盖其全部模型，包括历史模型。不得直接将单个组合键当作整个供应商。
- 统一查询条件为“时间范围 ∩ 所选供应商”，已有模型筛选若启用则继续取交集；未选择具体供应商时表示全部。
- 上方调用数、成功／异常数、Token、费用、缓存命中率、平均速度、首 Token，以及趋势图、活动日历和三个页签均使用相同供应商范围；日历沿用现有固定年度时间窗口，并明确其窗口与页面时间范围的区别。
- 所有聚合由后端在过滤后的调用集合上计算；禁止只过滤下方表格、上方保留全量指标。缓存命中率用筛选后的 Token 总量计算，成功率用筛选后的成功与总调用数计算，速度与首 Token 按第 3 节计算。
- 页签数量标记如显示，分别取当前筛选下的调用总数、供应商数、模型数，不使用当前已加载行数。
- 更改筛选时重置调用列表分页；供应商选项保持完整，不因当前结果为空而丢失已选项或无法切回其他供应商。
- 切换筛选后的请求期间显示加载状态；旧请求晚返回不得覆盖新结果，不将新筛选条件与旧全量统计混合展示。无匹配调用时显示空态，速度与首 Token 显示 `—`。

### 1.2 独立调用详细统计的供应商筛选

- 保留侧栏现有调用详细统计入口，在该页面操作区增加同口径的供应商筛选。
- 从概览跳转完整调用页面时携带当前时间范围和供应商选择；后续两个页面各自维护筛选，互不隐式改写。
- 列表查询、总数和后续刷新均携带当前筛选；后端先按供应商和时间过滤，再排序、分页或应用条数上限，避免前端过滤最近一批调用导致漏数。
- 概览调用记录与独立调用页面复用调用列表展示及单次详情能力，避免复制两套筛选和详情逻辑；现有调用详情的请求、响应及诊断信息继续由原详情组件负责。

### 1.3 模型 Token 消耗直接展示

当前表格只有输入、缓存读／写、输出等分项，缺少直接可读的模型总量，需要用户自行相加；新增“总 Token”作为主要指标。

- 模型名称之后第一列显示该模型的总 Token，例如 `7.76M`，无需展开或悬停；供应商页签同样直接显示供应商总 Token。
- 默认按总 Token 消耗从高到低排序，可切换升降序，并保留平均速度等已有排序能力；排序使用原始整数，不使用 K／M 格式化文本。
- 总 Token 单元格同时显示当前筛选内的消耗占比及简洁比例条，便于直接比较各模型；比例条以当前筛选下总 Token 为基准，不以最大单个模型为基准。
- 直接复用后端 `token_usage`，与上方 Token 消耗卡片一致；当前口径为非缓存输入 + 缓存读取 + 缓存写入 + 输出，不重复加上已经包含缓存的提示词总量。
- 总量主值使用 K／M 等紧凑格式，悬停显示完整整数及分项；现有输入、缓存读写、输出列保留在靠后位置，作为用量组成明细。
- 占比为“该模型总 Token / 当前筛选的整体总 Token”，与表格是否分页或只显示部分行无关；分母为零时显示 `—`，比例条为空。
- 总 Token 与占比统计不套用平均速度的短样本门槛；有记录的用量继续计入，不能因速度不可用而丢弃用量。
- 常用窗口宽度下优先保证模型名称、总 Token 可见，明细列可横向滚动；不能让总消耗被速度、费用或大量明细列挤到屏幕外。

```text
模型名称 ──> 总 Token（主值 + 当前筛选占比）──> 平均速度 / 首 Token ──> 调用、用量明细与费用
                 ↑
         默认按原始总量降序排列
```

## 2. 概览：缓存命中率直接显示百分比

当前缓存命中率使用半圆仪表盘展示。

- 改为与其他统计卡片一致的数值展示，例如 `99.99%`，移除半圆仪表盘和对应动画。
- 沿用现有公式：缓存读取 Token /（缓存读取 Token + 非缓存输入 Token），保留两位小数。
- 保留说明提示及“计入缓存创建”的补充口径，不改变统计计算。
- 分母为零时显示“暂无数据”，避免把无数据显示成 `0.00%`；有效分母下缓存读取为零时显示 `0.00%`。

## 3. 概览：平均速度与首次响应速度

- 概览统计卡片增加“平均速度”和“首 Token”，分别展示当前时间范围、筛选条件下的整体输出速度与首次实际输出等待时间，例如 `94 tok/s`、`1.3s`。
- “首次速度”沿用统一速度计划中的“首 Token”名称，以秒表示等待时间；提示说明包含非空正文、思考与工具输出，排除响应头、心跳和空事件。
- 下方供应商、模型两个页签的汇总表同步增加“平均速度（tok/s）”“首 Token（s）”两列，放在名称与总 Token 之后，平均速度在前；总消耗的展示优先级高于速度和分项明细。
- 整体平均速度与每行平均速度均按 `Σ有效样本输出 Token / Σ有效样本生成时间` 计算，生成时间不包含首输出等待；不能直接平均单次速度或各行速度。
- 整体首 Token 取当前范围内有效成功流式调用等待时间的中位数；供应商行取该供应商跨模型的有效调用中位数，模型行取所选供应商范围内该模型的有效调用中位数，不能平均或再次取各行中位数。
- 样本筛选、测量与估算分组、精度及不可用原因复用统一速度计划：速度使用成功流式调用中输出不少于 100 Token、生成时间不少于 100ms 的样本，首 Token 不受该输出门槛限制；模型测试不混入业务速度统计。
- 速度 ≥1 时取整数，小于 1 时保留一位小数；估算值加 `≈`，缺少有效数据时显示 `—`，提示展示样本数和不可用原因。
- 切换时间范围、供应商或模型筛选及刷新时，整体卡片和表格同步更新，不将无计时的历史记录视为零。

目标统计卡片顺序：

```text
缓存命中率 | LLM 调用 | 平均速度（tok/s）| 首 Token（s）| Token 消耗 | 估算费用
```

## 4. 主题：支持跟随系统

当前主题设置仅提供“默认暗色”和“默认亮色”。

- 增加“跟随系统”选项，与现有两个主题选项并列。
- 选择后，根据系统当前的深浅色偏好应用现有默认暗色或默认亮色主题。
- 应用运行期间系统主题改变时，界面自动同步，无需重启。
- 保存用户选择的“跟随系统”模式，而非当时解析出的暗色或亮色；重启后按系统当前偏好显示。
- 手动选择“默认暗色”或“默认亮色”后固定使用该主题，系统变化不再影响显示。
- 启动时在页面渲染前应用所选模式，避免先显示错误主题再切换；已有手动选择继续生效。

```text
保存的主题选择 ──> 启动时应用 / 用户切换
                  ├── 默认暗色或默认亮色 ──> 固定应用所选主题
                  └── 跟随系统 ──> 读取系统偏好 ──> 应用对应主题
                                      ↑                  │
                                      └── 系统偏好变化 ──┘
```

## 5. 金额：支持人民币与美元换算显示

- 增加美元（USD）／人民币（CNY）显示切换，默认沿用美元；概览页面操作区可切换，设置页可配置显示币种和换算汇率。
- 汇率统一定义为 `1 USD = R CNY`，由用户配置正数，不内置未经确认的实时汇率；人民币显示注明“按设置汇率折算”，可查看当前使用的汇率。
- 尚未设置有效汇率时，选择人民币应引导配置；不将无效、零或负汇率用于折算，也不把未换算的美元金额标成人民币。
- 概览费用卡片、缓存读写费用、三个页签的费用与单次均值、费用趋势坐标及提示，以及独立调用列表／详情中的金额展示统一使用所选币种。
- 所有统计继续以现有美元金额累计，显示时使用 `人民币金额 = 美元金额 × R`；切回美元直接读取原美元金额，不对已换算或已格式化的结果反向计算。
- 保留现有十进制精度处理，先汇总再换算，最后格式化；小额费用不因固定两位小数全部变成零，提示可查看更高精度及原美元金额。
- 美元使用 `$`／`USD`，人民币使用 `¥`／`CNY`，图表坐标与提示明确单位；未定价、用量不完整等状态继续保留。
- 保存显示币种和汇率，重启后恢复；更新汇率后当前金额同步重新显示。此汇率用于当前查看时的折算，不表示历史支付时的实际汇率。
- 显示切换不改写历史费用、冻结价格快照或模型定价输入的美元单位，也不影响费用排序、时间范围和供应商筛选。

```text
数据库中的美元金额 ──> 当前筛选内汇总 ──> 显示币种
                                          ├── USD ──> 美元格式化
                                          └── CNY ──> × 设置汇率 ──> 人民币格式化
设置页拥有汇率配置；共享状态保存币种与汇率，各页面使用同一换算规则。
```

## 6. 概览趋势：支持曲线图

- 现有用量柱状图增加“柱状 / 曲线”切换，参考用户提供的 CC Switch 截图，曲线使用总量曲线配浅色面积填充。
- 保留现有柱状图及输入、缓存读取、缓存写入、输出的堆叠明细；曲线图展示每个时间桶的总 Token 或总费用，悬停仍可查看同一时间桶的分项明细。
- “Token / 费用”与“柱状 / 曲线”独立切换，两种图形均支持 Token 和费用；费用曲线随 USD／CNY 选择同步换算坐标和提示。
- 两种图形使用同一时间分桶、时间范围和供应商筛选结果；切换图形只改变呈现，不重新定义统计或更改上方卡片和页签数据。

- 保存图形偏好，首次沿用现有柱状图；切换时间、筛选、页签或重启后保留用户选择。
- 复用现有 ECharts 和趋势组件，不额外引入图表库；切换图形、统计维度和币种的控件统一放入页面操作区。

    └── 携带筛选跳转 ──> 独立调用页面拥有后续筛选 / 刷新 ──> 单次调用详情

切换页签：沿用当前筛选；切换供应商：重新查询并重置调用分页。
筛选只控制查询，不改变持久化调用；既有采集持续写入数据库，刷新仍沿用当前条件。
